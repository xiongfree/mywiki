# LLM 架构演进深度脉络（2017 → 2026）

> 逐篇精读三年 LLM 架构论文后写成的一份**带立场判断**的技术综述。不只梳理"有哪些技术"，而是讲透**五大路线的代际脉络（谁→谁→谁、为什么这么演化）**、**每个技术的机制原理（公式级 + 数值举例）**，以及**路线与路线之间的横向耦合关系**。

## 这篇文档想解决什么问题

市面上的架构综述多数停在"技术清单"层面：列出 RoPE、GQA、MoE、Mamba，各讲一段，读完知道名词但不知道**为什么是这个顺序演化出来的**，也不知道**这些模块之间怎么互相牵制**。

本文换一个组织方式：把 Transformer 拆成**位置编码、归一化、残差连接、FFN/MoE、注意力**五条独立演化的路线，每条路线纵向追代际传承，再横向找路线间的耦合与冲突。核心结论一句话——

> **到 2026 年，位置编码、归一化、FFN 三块已基本收敛；残差连接（2024 起被动刀）与注意力（持续至今）是仅剩的两个激烈战场。Block 内部的矿脉挖尽，创新已上移到层间拓扑。**

## 几条核心判断（摘自 §2）

- **矿脉转移**：单 Block 的设计自由度已被穷举，创新转移到跨层、跨 Block 的连接与配比。2026 年四篇旗舰论文无一发明新算子，全部在做层间编排。
- **同一场战争的五个投影**：五条路线共享隐藏变量 n（上下文）/ L（深度）/ N（参数）——整部架构史是一部对抗规模膨胀的边界工程史。哪个标量先撞墙，哪条路线就先被激活。
- **收敛看目标函数维度**：单目标路线（PE、Norm、MoE）率先收敛，注意力因五维互相打架（显存 × 算力 × 精度 × 长程检索 × 训练稳定）持续百花齐放。
- **稀疏的第四轴**：MoE 在专家维、稀疏注意力在 token 维、MLA 在特征/秩维——三个正交轴都已可学习稀疏，唯独**深度（层）维度**仍是固定深度，是尚未开发的自由度。
- **工程兑现率决定成败**：架构实际收益 = 理论收益 × 工程兑现率。Flash Attention 让 O(n²) "不疼"，反而延后了稀疏/线性的紧迫性；KV 量化与 MLA 是**乘法叠加**（总省 ~98%）。
